# Observed-shape relevance of startup mass

**Bounded diagnostic only.** This weights the two-layer startup added mass by three observed baseline deformation shapes. It does not validate an eigenmode, predict frequency, establish a rigorous dynamic error bound, or add a local pass/fail gate. The full cap refinement still requires its completed assessment and comparison.

Baseline moving-assembly rigid translation and proper rotation are removed using the same physical-mass weighted fit as the assessor. The resulting residual displacement field is transferred through all 4092 ordered midpoint bisections. Original moving nodes are identical; every new node is accounted for. Maximum rounding difference between an emitted midpoint coordinate and its parent-edge mean is 6e-12 m.

For each region, the reported percentage is `100 × sum(added_mass × |residual|²) / sum(physical_nodal_mass × |residual|²)`. It measures added inertia participation for that sampled deformation shape.

The observed shapes give central-rail participation of approximately 0.118–0.120%, far below the deliberately conservative worst-node concentration bound. This supports a limited statement about these observed shapes. Modes or transients with different localization can weight the scaled nodes differently. The baseline shapes themselves come from the coarser elastic model and are not independent material validation.

## New versus inherited added mass

Original cap nodes contain 2.6170 mg added mass in the baseline and 5.8599 mg in the two-layer mesh: an increase of 3.2429 mg. New cap midpoint nodes carry 11.0057 mg. The refinement therefore adds approximately 14.2486 mg beyond the inherited cap scaling.

The worst cap nodal ratio from the startup audit is **inherited**, not introduced by refinement: node 18968 at (-116.000, 18.250, 30.122) mm has exactly the same 0.378788 mg added mass in both cases. Its added/physical nodal mass ratio remains 323.28%. This is the original outer cap end/sidewall location.

The largest changes on original nodes occur on the refined rails and their immediate transition near X = ±86–88 mm. The JSON lists these nodes and separates original-node versus new-node contributions to each observed shape. New midpoint nodes provide roughly three quarters of the shape-weighted added inertia at the selected times.
